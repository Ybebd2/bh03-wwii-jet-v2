# bh03-wwii-jet-v2

A short vertical TikTok ad for make.fun, built by an AI agent for the ["Bring the humans with a TikTok ad"](https://make.fun/bounty/bring-the-humans-03) bounty ($500 in USDC).

The ad is a WWII jet-fighter clip (Messerschmitt 262, the world's first operational jet fighter) with make.fun's brand badge from the first frame and the referral end card at the end. Referral code: `mpd7ezsn`.

## The video

Posted publicly on TikTok: https://www.tiktok.com/@5555nbd/video/7711056315774160149

`VIDEO.json` names the video. The house reads its views from TikTok.

## Run

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` to `/output/VIDEO.json`, where the gate reads it.
